# Atelier Solaire

Outil en ligne d'étude photovoltaïque : production horaire (PVGIS), ombrage, 3D, dimensionnement électrique, stockage et rapport client.

Les données (comptes, composants, projets) sont stockées dans Supabase et protégées par des règles d'accès : seuls les comptes validés par l'administrateur y ont accès.
